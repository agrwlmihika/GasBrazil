# GasBrazil
Economic analysis project focusing on collusion in the Brazilian fuel industry


Research project studying how gas stations in Brazil's Distrito Federal set prices based on their competitors' locations, using spatial econometrics. Conducted as a research assistant under Professor Marco Duarte, UNC Department of Economics.

What this project does
Estimates a Berry-style logit demand model for gas stations, accounting for how nearby competitors affect pricing
Builds spatial competition measures directly from geographic distance between stations
Uses instrumental variables (IV) to address endogeneity in price and market share estimates, with panel fixed effects
Computes price elasticities and diversion ratios to quantify how customers would shift between competing stations
Produces a full written report (LaTeX/Overleaf) summarizing methodology and results
Data
Uses DENATRAN vehicle fleet data (Frota) to construct market size
Station-level pricing and location data for Brazil's Distrito Federal
Tools
R, using fixest for panel/IV regressions
LaTeX (booktabs, threeparttable) for report tables

Status
Ongoing research project, paused for summer 2026, resuming in fall.
